Каталог, указанный в настройках CheckAI → "Дайджесты", хранит текстовые ежедневные дайджесты посещений ИИ-ботов. Их можно использовать для анализа в других системах и/или отправки на электронную почту или в мессенджеры (механизм отправки не включен в данный проект).

Каждый файл содержит данные за предыдущий календарный день, разбивку по сайтам и видам ботов.
Отключённые боты и компании в расчёт не включаются.

Для формирования вручную нажмите в панели CheckAI:
Настройки -> Дайджесты -> Сформировать дайджест сейчас.

Также можно выполнить команду от пользователя, которому доступны база данных и выбранный в настройках каталог:
php /var/www/checkai.analitica-soft.ru/bin/generate-digest.php

Для ежедневного дайджестов включите флажок "Формировать ежедневный дайджест" в настройках. Далее добавьте в cron пользователя веб-сервера запуск формирования в 01 часа ночи:
0 1 * * * /usr/bin/php /var/www/checkai.analitica-soft.ru/bin/generate-digest.php

Файлы создаются в каталоге, заданном в настройках, с именами вида YYYYMMDD-HH-MM_digest.txt.
Если папка проекта или путь к PHP отличаются, замените их в команде.
